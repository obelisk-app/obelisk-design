# Docs and Specs

## Placement

- Cross-project design rules live in this repository.
- Product-specific event specs, deployment notes, and API contracts live next to the implementation repo.
- Link to source documents instead of copying long specs.

## Writing Style

- State the trust boundary first for security docs.
- Make operational consequences explicit: what breaks, who can recover, and what requires restart or migration.
- Keep accepted defaults separate from future hardening ideas.
